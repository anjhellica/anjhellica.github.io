Overview: Inventory Analytics & Food Waste Monitoring Platform for MSMEs

Role: Project Lead, UI/UX Designer, Documentation Contributor

Tools: Figma, Lovable (AI-assisted web application builder), Google Docs, Lucidchart

Why This Mattered

Maginhawa Street is one of Quezon City's most active food districts and was officially recognized as the Maginhawa Art and Food Hub. Despite the area's vibrant food industry, food waste remains a significant challenge. Many inventory systems help businesses monitor stock shortages, but few provide insights into overproduction, overpurchasing, and food waste generation.

What I Did
  • Helped refine the overall project concept and system direction.
  • Created the project's first application prototype.
  • Redesigned the user interface through Figma wireframes and layouts.
  • Refined system features based on project requirements and user needs.
  • Conducted quality checks focused on usability and user experience.
  • Delegated tasks and coordinated project activities.
  • Assisted in documentation review and editing.
  • Supported potential client outreach and validation activities.
Outcome

Developed a functional web application prototype that is currently accessible and testable.

Project Link: https://menuwiseapp.lovable.app/

Key Learning

Effective business solutions start with understanding operational problems rather than immediately focusing on technology. This project strengthened my skills in product planning, requirements analysis, team coordination, and user-centered design.
